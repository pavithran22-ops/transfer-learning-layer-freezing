# Notebooks

This directory is reserved for Jupyter notebooks used for interactive
experimentation, exploratory data analysis (EDA), and step-by-step walkthroughs.

## Suggested notebooks

| Notebook | Purpose |
|---|---|
| `01_eda.ipynb` | Explore dataset — class distribution, sample images |
| `02_model_a_demo.ipynb` | Step-by-step walk-through of Model A training |
| `03_model_b_demo.ipynb` | Step-by-step walk-through of Model B fine-tuning |
| `04_comparison.ipynb` | Side-by-side metric comparison and visualisations |

## Installation

```bash
pip install jupyter
jupyter notebook
```

> **Note**: Notebook checkpoints (`.ipynb_checkpoints/`) are excluded from Git.
